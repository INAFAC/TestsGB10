# Registros y reproducción

Las mediciones proceden de entradas sintéticas. Los registros publicados sustituyen rutas personales, direcciones privadas y nombres locales de equipo. Los originales completos se conservan fuera del repositorio. El inventario indica la huella del original, la del archivo publicado y si se ha aplicado esa sustitución. Las mediciones numéricas y los errores se conservan.
