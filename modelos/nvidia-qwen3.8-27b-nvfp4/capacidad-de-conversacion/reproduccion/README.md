# Reproducción y registros

[Volver a los resultados](../README.md)

El [plan](../plan.json) describe la carga y los criterios antes de medir. Aquí se conservan el estado del controlador, el piloto y los scripts efectivamente ejecutados. Los registros sustituyen rutas personales, direcciones privadas y nombres locales. Las mediciones y los historiales ficticios se mantienen junto a cada prueba. El [inventario](inventario.json) permite comprobar su procedencia.
